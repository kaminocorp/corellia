# Phase 17: Round-5 review, Mac and box on one backend, deployment hardening

**Date:** 2026-10-30. **Branch:** `feat/vision-implementation`. **Changelog:** 0.15.17. **Roadmap:** [`../executing/roadmap.md`](../executing/roadmap.md) Phase 17. **Input:** the fifth independent review ([`../executing/review-2026-10-30-round5.md`](../executing/review-2026-10-30-round5.md), against `681651a`, verdict "alpha-ready to deploy today; beta-ready in everything that can be checked without the owner"), committed with this phase.

## Summary

The review found no code blocker on the recommended paths and three groups of non-blocking defects: the Mac and the box on one backend (two voices, a global heartbeat, no documented way to run both), deployment hardening (dev mode open behind a same-host proxy; the Docker image unable to write `/data` while reporting itself healthy), and three small items (the history cache window, `box/release/` untracked, glance cards covering a chart). This phase takes all of them.

- **One voice.** The kiosk always speaks; a browser is silent while a kiosk is connected to the same backend and says so in the mic indicator ("sound on the display"); `Ctrl+Shift+M`, `?quiet=1` and `?quiet=0` override, remembered per browser.
- **Per-client heartbeat.** Heartbeats are tagged `kiosk` or `browser`; `/healthz` reports `kiosk_heartbeat_age_s` apart from the generic age and the watchdog reads the kiosk's, so an open Mac tab cannot hide a hung kiosk. The kiosk script keeps `kiosk=1` in the URL whatever `CORELLIA_KIOSK_QUERY` says.
- **Dev mode refuses proxied requests.** Any `/api` request carrying `X-Forwarded-For`, `Forwarded`, `X-Real-IP`, `X-Forwarded-Host`/`-Proto`, `Via` or a `Tailscale-*` header is a 403 with "dev mode: requests through a proxy need CORELLIA_DEVICE_TOKEN", logged once; a proxy listed in `CORELLIA_TRUSTED_PROXIES` is exempt. Both READMEs say why next to the `tailscale serve` line.
- **The store is loud.** `store.New` proves the data directory writable and `cmd/api` exits with the fix in the message when it is not; later write failures are recorded, reported on `/healthz` (`ok: false`, `store_ok`, `store_error`), returned to the client with each heartbeat, published as a `session_error` (`persist`), and shown as a persistent "can't save" banner. The Dockerfile creates `/data` owned by the app user before `VOLUME`.
- **The history prefix holds.** The history window drops ten entries at a time instead of one pair per turn, so the provider's cache prefix is identical for several turns; `CORELLIA_CACHE_TTL=1h` is available for the static prefix.
- **`box/release/` is gitignored.**
- **Cards stay off the data.** Floating overlays render in their own layer over the stage; beside a full visual they share a right-hand column (the gutter) and the visual ends before it; beside a panel they move to the agent's side.

No contract change. Additions: `session.Options.HistoryStep`, `anthropic.Options.CacheTTL`, `CORELLIA_CACHE_TTL`, `httpsrv.Deps.StoreHealth`, `Heartbeat.WithStoreHealth`/`KioskAge`, `store.Store.Err`/`Healthy`; on the client `voice/speaker.ts`, `VoiceStatus.speaker`, `VoiceDeps.toggleSpeaker`, `Renderer`'s `layer` prop, `SessionState.storeError`/`kioskConnected`, `StoreBanner`.

## Design decisions

- **The display speaks, by default.** Of the review's three options, a per-client mute alone would have needed the owner to remember to mute the Mac every time; a server-designated speaker would have needed a client-election protocol. The kiosk's heartbeat already tells the server a display is up, and the heartbeat answer already reaches every client, so "a browser is silent while a kiosk is connected" costs one field and one pure function, with the explicit overrides for the cases it gets wrong. The state is always visible in the mic indicator.
- **Heartbeats tagged, not restricted to the kiosk.** Posting heartbeats only from the kiosk would have fixed the watchdog but lost browser liveness and the channel the status now rides on. Tagging keeps both; the watchdog reads the kiosk field and falls back for older backends.
- **Refuse proxied requests rather than warn.** A warning in the log would not stop the tailnet from reaching the confirm gate. The refusal names the fix, costs nothing on the recommended paths (no proxy adds those headers to a direct loopback request, and the Vite dev proxy adds none), and the one configuration that legitimately forwards in dev mode (`CORELLIA_TRUSTED_PROXIES`) is exempt because the owner wrote it down.
- **Exit at boot, report at run time.** An unwritable directory at boot is a configuration error and the process should not come up; a directory that stops accepting writes later (disk full, ownership changed under a running container) must not take the display down, so it is reported everywhere the owner looks (`/healthz`, the page, the stream, the log) and the session keeps serving.
- **Steps, not a bigger window.** A larger window would hit the cache for longer but cost more tokens on every turn and still slide; dropping ten entries at a time keeps the token cost near the old 20-entry window (20-29 entries) and makes the prefix identical for about five turns. The TTL is opt-in because it doubles the write price and the live run has not happened yet.
- **Overlays in their own layer.** Rendering the overlay groups inside the zone made their anchors relative to whatever rectangle the zone had, which was invisible in glance mode (zone = whole stage) and wrong for both the gutter and the panel's left side. One layer over the stage fixes both and leaves the zone to the visual. The gutter is on the right so a full visual shrinks from its right edge (transition 500 ms) and grows back when the cards decay; a panel does not change size, its cards go over the agent, which is decoration.

## How to run

As before: `pnpm install`, `pnpm -C client build`, `cd backend && go run ./cmd/api`, open http://localhost:8080. To see the speaker policy without a box, open a second tab at `http://localhost:8080/?kiosk=1`: the first tab's indicator switches to "sound on the display" within a heartbeat (30 s) and only the kiosk tab speaks; `Ctrl+Shift+M` in the first tab brings its sound back. To see the gutter: "show me Lisbon on the map", then "remind me in 5 minutes to stretch". To see the store banner: make `backend/data` read-only while the server runs and send a message. For the proxy refusal: `curl -H 'X-Forwarded-For: 1.2.3.4' http://localhost:8080/api/session`.

## Known gaps

- The speaker policy follows the heartbeat (30 s interval, 90 s freshness), so when the box comes up the Mac keeps speaking for up to one heartbeat, and when the box dies the Mac stays silent for up to 90 s. `Ctrl+Shift+M` is immediate.
- Two kiosks on one backend both speak (both are `on`); the policy only distinguishes kiosk from browser.
- A full visual reflows when a card arrives and when it decays (a MapLibre map resizes, a chart redraws). Nothing is covered, at the price of motion.
- Docker is still unbuilt here (no socket); the `/data` fix is checked by reading and by simulating an unwritable directory with the binary.
- Nothing in `box/` has run on hardware.
- Whether the cache hits in production, and whether `1h` pays for itself, is for the owner's live run (checklist A).
